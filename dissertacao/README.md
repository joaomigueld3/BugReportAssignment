# dissertacao/: material por seção

Material de escrita agrupado por seção da dissertação, alimentado pelo agente `registro-dissertacao`. `NOTES.md` continua sendo o registro cronológico por etapa e `DECISIONS.md` o registro das decisões; aqui o mesmo conteúdo aparece reorganizado para quem está escrevendo um capítulo.

| Arquivo | Seção da dissertação |
|---|---|
| [metodologia.md](metodologia.md) | Ambiente, dataset, grão, filtros, rótulo, split |
| [resultados.md](resultados.md) | Tabelas e números medidos, por tema |
| [ameacas_validade.md](ameacas_validade.md) | Limitações medidas, com magnitude |
| [caminhos_descartados.md](caminhos_descartados.md) | Hipóteses refutadas e erros corrigidos |
| [proveniencia.md](proveniencia.md) | Hashes, versões, datas, comandos |

Convenções, herdadas de `CLAUDE.md`:

- Toda afirmação é rotulada `(fato)` com o script que a produziu, `(inferência)` com o raciocínio, ou `(não confirmado)` com o que faltaria.
- Nenhum nome ou e-mail de desenvolvedor. Endereços de caixas de componente não são pessoais.
- Decisões de método pertencem ao pesquisador e ficam em `DECISIONS.md` com status aberta.
